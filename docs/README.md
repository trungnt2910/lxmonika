# lxmonika Documentation

[![Discord Invite][2]][1]

This folder contains helpful documentation for contributors getting started with `lxmonika`.

## Introduction

`lxmonika` is a framework for building and managing Windows Pico process providers.

## Getting Started

You can download official builds of `lxmonika` on [NuGet](https://www.nuget.org/packages/monika).

You can also download `lxmonika` [here](https://www.nuget.org/api/v2/package/monika).
Extract the file as a `.zip` archive.
